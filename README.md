# ManualShark 🦈

Ручной поисковик игр из CheapShark API. Вы не можете просто взять и вбить в поисковую строку нужную игру, потому что поисковой строки здесь вообще нет. Вместо этого вы должны набрать случайных игр и вручную отобрать интересующие вас.

Сайт предоставляет возможность свободно перемещать карточки с играми и подсвечивает нужные игры для удобства ручного поиска.
